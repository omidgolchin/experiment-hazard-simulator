# Data sources

There are none. Every number in this repository — the sweeps, the
figures, the playground — is generated by the simulation model in
`sim/model.py` / `docs/sim.js` from seeded random draws. No empirical
dataset is used, downloaded, or redistributed.

The hazard list and checks come from the author's own
[agent-experiment-methodology](https://github.com/omidgolchin/agent-experiment-methodology)
skill (see DECISIONS.md, entry 1, for a note on access at build time).
