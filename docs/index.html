Experiment hazard simulator

Claim: one design hazard slipping into an agent experiment is enough to produce confident, wrong “significant” results at realistic settings — and each hazard is caught by one specific check. Toggle hazards below and watch the false-positive rate move.

The simulator runs 1,000 simulated experiments per setting in your browser. An experiment compares condition A and B on a sample of tasks with several seeds each; the true effect is whatever you set (default 0, so every “significant” result is a false alarm). The grey comparison is always the same design with all hazards off.

How to read the results

With δ = 0 the headline number is the false-positive rate: how often the study claims an effect that does not exist. A clean design gives ≈ 5%. With δ > 0 it is power. The histogram shows the distribution of estimated effects (success-rate difference, B − A) across the 1,000 experiments, with the clean design overlaid.

Each active hazard also shows the check that catches it, quoted from my agent-experiment-methodology skill.
